## 任务 1.2 修复路由树问题

`internal/routers/router.go`：

1. 删掉第 71 行重复的 `Get("list", ...)`（和第 72 行 `GET("list", ...)` 重复，且 `Get` 这个小写变体函数根本不应该存在，一并删掉定义）。
2. **统一 AuthMode 语义**。现在挂在 `AdminAuthHandler()` 中间件下的路由，很多标的是 `AuthLogin`，语义自相矛盾。整理为：
   - `AuthNone`：不需要登录（ping、login）
   - `AuthLogin`：需要登录但不校验权限（获取个人信息、改个人资料）
   - `AuthPerm`：需要登录且过 Casbin（所有管理类 CRUD）
3. 思考并重构：现在是「按分组挂中间件」决定是否鉴权，AuthMode 只是个摆设标签。gin-layout 的做法是**路由注册时根据 AuthMode 自动决定挂哪些中间件**。对照阅读：

```text
gin-layout/internal/routers/meta.go
gin-layout/internal/routers/register.go
gin-layout/internal/global/api_auth_mode.go
```

思考题：

- gin-layout 的 `AuthModeNone / AuthModeLogin / AuthModeAuth` 是在哪一步转化成中间件行为的？
- 为什么它要把每个路由的 method+path+auth_mode 收集起来？（提示：和"API 管理、Casbin 策略同步"有关，阶段五会用到）
