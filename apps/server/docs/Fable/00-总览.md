## 一、你现在的进度（2026-07 评估）

已完成（做得不错的部分）：

- cobra 命令行启动（`cmd/root.go`、`cmd/service/service.go`），含优雅关闭
- 配置加载（`config/config.go`，yaml 反序列化）
- 声明式路由树（`internal/routers/defs.go` + `register.go`），带 AuthMode 概念
- 登录 + JWT（`internal/controller/login.go`、`internal/service/auth.go`）
- 统一响应 / 错误码（`internal/pkg/response`、`internal/errors`）
- admin_user / role / menu 三个模块的 CRUD
- Casbin 初始化和权限中间件（做到一半）

存在的问题（阶段一要解决的）：

1. `internal/access/casbin/endorcer.go` 有编译级错误：
   - import 了 `github.com/wannanbigpig/gin-layout/internal/utils/filePath`（别人项目的内部包，根本 import 不到）
   - `model.NewModelFormFile` 拼写错误（应为 `NewModelFromFile`）
   - 文件名 `endorcer.go` 拼写错误（应为 `enforcer.go`）
   - `middleware/admin_auth.go` 使用了 `casbinx` 但没有 import
2. `internal/routers/router.go` 第 71 行：`Get("list", ...)` 和 `GET("list", ...)` 重复注册
3. 路由树里 AuthMode 声明混乱：挂在权限中间件下的路由，很多标的却是 `AuthLogin`
4. 目录结构和 gin-layout 有偏差：`middleware`、`global` 在项目根目录（gin-layout 在 `internal/` 下）
5. 没有日志系统（zap）、没有 Redis、没有数据库迁移、没有任何测试

## 四、学习方法（每个任务都遵循这个循环）

```text
1. 读文档里的任务说明，先不看 gin-layout 源码
2. 自己实现最小可用版本，跑通
3. 打开 gin-layout 对应文件，逐行对比差异
4. 回答文档里的"思考题"（建议写在 docs/Step/ 下的笔记里）
5. 用学到的做法小幅重构自己的实现
6. 核对"晋级标准"
```

三条铁律：

1. **禁止复制粘贴 gin-layout 的代码。** 可以看、可以模仿思路，但每一行都要自己敲。import 别人的 internal 包这种事不要再发生。
2. **每个任务完成后都要能编译、能启动、接口能用 curl 验证。** 不留半成品过夜。
3. **从阶段二开始，每个新写的 pkg 至少配一个 `_test.go`。** 不要把测试全堆到阶段七。

## 五、通用验收命令

每个阶段结束前，以下命令都必须通过：

```bash
cd GinAdmin
go build ./...        # 全项目可编译
go vet ./...          # 无静态检查问题
go test ./...         # 已有测试全绿（阶段二起）
go run main.go server # 服务可启动
curl http://127.0.0.1:8080/ping   # 返回 pong
```
